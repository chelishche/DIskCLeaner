# DIskCLeaner
EN:
DiskCleaner is a program for efficiently cleaning the C: drive, allowing you to free up disk space without affecting important files. 

The application includes settings that let you choose what to delete and what to keep, along with other configuration options.  You can download the ready-to-use build from the Releases section.

🇷🇺RU:
DiskCleaner - это программа для эффективной очистки диска C, позволяющая уменьшить место при этом, не трогая важные файлы.

В приложении есть настройки, там можно выбрать, что удалить, а чего нет и другие настройки.

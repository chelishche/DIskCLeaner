# DIskCLeaner
DiskCleaner is a program for efficiently cleaning the C: drive, allowing you to free up disk space without affecting important files. The application includes settings that let you choose what to delete and what to keep, along with other configuration options.  You can download the ready-to-use build from the Releases section.

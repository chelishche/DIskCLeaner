# DiskCleaner

---

EN:

DiskCleaner is a program for efficiently cleaning the C: drive, allowing you to free up disk space without affecting important files. 

The application includes settings that let you choose what to delete and what to keep, along with other configuration options.

You can download the ready-to-use build from the [Releases](../../releases) section.

---

RU:

DiskCleaner — это программа для эффективной очистки диска C, позволяющая освободить место, не трогая важные файлы.

В приложении есть настройки, где можно выбрать, что удалять, а что нет, а также другие параметры конфигурации. 

Готовую сборку можно скачать в разделе [Releases](../../releases).
